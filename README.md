# 电量守护 / Battery Guardian

给"经常忘记插电、直到自动关机才想起来"这件事做的 Windows 小工具。

它不试图做"更醒目的提醒"，因为提醒失效的原因不是不够醒目，而是**忽略它的成本为零**。
所以它做的事是：把忽略的代价从 0 抬起来，直到你必须起身插一下。

---

## 六层机制

不是六个并列开关，是**同一条升级链**。电量往下走，压强逐级升高；插上电，全部立刻安静。

| 层 | 触发 | 做什么 |
|---|---|---|
| L1 换触发点 | 50% | 在你还顺手的时候提示，而不是 20% 才打断你 |
| L2 常驻浮条 | 一直 | 把电量翻译成"还能撑多久"，不弹窗、不消失 |
| L3 说谎检测 | 20% | 弹确认框，唯一按钮是"已插电"，点下去真的读充电状态 |
| L4 即时代价 | 10% | 屏幕顶部一条横幅，真的占掉你一块屏幕（默认关闭） |
| L5 电费账本 | 双击浮条 | 把"用电池省钱"这笔账算给你看 |
| L6 保底层 | 8% | 60 秒倒计时后自动休眠，让最坏结果不是硬关机 |

**L3 是核心。** 那个按钮不是"我知道了"，而是"我已插电"——点下去会调用
`GetSystemPowerStatus` 校验 AC 状态。没插电，窗口就在；60 秒后它再大一圈。
右上角的 × 也接成了同一个校验，所以没法用 × 糊弄过去。

**L6 为什么是休眠不是关机。** 硬关机到 0% 是深度放电，对锂电池最不友好，而且丢数据；
休眠会把内存写进硬盘再断电，醒来还是原样。两者代价差很远。

## 吸附与收起

浮条可以拖到**屏幕左右边缘**吸附，鼠标移开 1.5 秒后自动收成一条 **6px 彩条**，
鼠标移上去滑出，点一下固定展开、再点一下取消固定。

收起态那条细带的颜色就是状态本身：

- 绿 = 已接电
- 琥珀 = 开始提醒（50% 以下）
- 红 = 正在逼你插（20% 以下）

**但这里有个必须处理的冲突：自动收起和"常驻可见"是打架的。**
常驻浮条的全部价值在于你不需要主动想起它；收起来就回到了"得想起来才看一眼"。

所以规则是：**只在安全档位允许收起，进入警告档位强制滑出并锁住，不允许收。**
默认阈值 `collapse_lock_below = 30`，即 30% 以下永远展开。
这样"碍眼"只在你电量充裕时被解决，该看的时候它一定在。

| 操作 | 行为 |
|---|---|
| 拖到边缘 28px 内松手 | 吸附到该侧，外侧直角、内侧圆角 |
| 拖离边缘 | 解除吸附，恢复四角圆角 |
| 鼠标移到收起态附近 | 滑出展开 |
| 鼠标移开 1.5 秒 | 自动收起（安全档位且未固定时） |
| 单击 | 切换"固定展开" |
| 双击 | 打开电费账本 |
| 右键 | 安静 30 分钟 / 1 小时 / 到明早 / 退出 |

## 逃生口

一个点不掉的窗口会变成恶意软件，所以留了三个出口：

- **长按 Esc 1.5 秒** —— 安静 30 分钟（真的没法插电的时候用）
- **右键浮条** —— 安静 30 分钟 / 1 小时 / 到明早
- **改配置** —— 把 `enable_fail_safe` 设为 `false`，保底层就不会动手

## 运行方式

### 方式一：源码（推荐自己用）

双击 `启动.bat`，它会自动找一个带 tkinter 的 Python 并启动，找不到会给出提示。

```
pythonw battery_guardian.py
```

### 方式二：exe（推荐发给别人 / 换机器）

双击 `build_exe.bat` 打包，产物在 `dist\BatteryGuardian.exe`，单个文件，**目标机器不需要装 Python**。

## 打包与跨设备可用度

这部分是 exe 最容易翻车的地方，逐条说明。

### 已经处理掉的坑

| 问题 | 处理 |
|---|---|
| 打包后 `__file__` 指向临时解包目录，配置写在那里退出即丢 | 冻结时改用 `%LOCALAPPDATA%\BatteryGuardian\data\` |
| 无控制台时 `--self-test` 等命令输出看不到 | 冻结且为命令行模式时，输出重定向到 `data\cli.log` |
| 图标文件在单文件模式下找不到 | 用 `sys._MEIPASS` 解析资源目录 |
| 打包环境缺 tkinter | `build_exe.bat` 会先探测 `import tkinter` 再建虚拟环境 |

### 跨设备行为

- **目标平台**：Windows 10 / 11 **x64**。ARM64 和 32 位不支持——PyInstaller 打的是本机架构，换架构要重新打。
- **无需 Python**：解释器、tkinter、Tcl/Tk 全部打进 exe。
- **体积**：实测 **11.7 MB**（单文件，Python 3.14 + tkinter）。
- **单文件代价**：每次启动会解压到 `%TEMP%\_MEIxxxx`，冷启动约 1–2 秒；`--onedir` 更快但要带一个目录。
- **配置位置**：`%LOCALAPPDATA%\BatteryGuardian\data\`。卸载 = 删 exe + 删这个目录，不留系统痕迹。
- **未签名**：SmartScreen 会提示"未知发布者"，需点"更多信息 → 仍要运行"；部分杀软会对 PyInstaller 单文件误报，加白名单即可。
- **系统能力依赖**：`GetSystemPowerStatus`（所有 Windows 都有）、`SetSuspendState`（休眠需系统开启休眠，失败自动回退 `shutdown /h`）。
- **无电池的台式机**：读数为空，浮条显示 `—`，不会崩。
- **高 DPI**：按系统 DPI 自动缩放，125% / 150% / 200% 均可。

### 已知限制

- **只在主屏工作**。`winfo_screenwidth()` 返回主屏尺寸，多显示器下浮条固定在主屏，不会跟到副屏。
- 吸附只做左右两边，上下不支持（横条吸上下排版会变形）。
- 自动收起依赖鼠标位置轮询（120ms 一次），不是系统级 hover 事件。

### 分发建议

`dist/` 在 `.gitignore` 里，**exe 不进仓库**——每次重新打包都会让仓库膨胀 12MB。
推荐做法是把 `BatteryGuardian.exe` 作为 **GitHub Release 附件**发布：

```bash
gh release create v1.0.0 dist/BatteryGuardian.exe \
  --title "v1.0.0" --notes "首个版本"
```

如果你更希望 exe 直接躺在仓库里，把 `.gitignore` 里的 `dist/` 删掉即可。

## 电费账本怎么算的

```
每次放电 d%：
  省下的电费 = 电池容量(Wh)/1000 × d/100 × 电价
  电池折损   = d/100 × 深度放电系数 × (换电池价格 / 循环次数)
```

默认假设（可在 `data/config.json` 里改）：

- 电池容量 60 Wh（按自己机器改，`powercfg /batteryreport` 里有设计容量）
- 电价 ¥0.60 / 度
- 换电池 ¥400，设计循环 600 次
- 低于 10% 的部分，折损系数 ×1.5（深度放电更伤）

按这组参数，一次满放电省下约 **¥0.04** 电费，同时消耗约 **¥0.67** 的电池寿命，
**比值大约 1 : 18**。

这个数字不是精确值，但量级是可靠的：电池折损比省下的电费贵一个数量级以上。
账本存在的意义不是精确核算，而是把"用电池省钱"这个直觉纠正过来。

## 顺手该做的一件事

工具只是兜底，系统层面还有一处更硬的保险：

**设置 → 系统 → 电源和电池 → 电池 → 关键电池操作**，改成「休眠」。
默认值通常是「关机」，这正是机器会硬关机的原因。改成休眠，就算所有提醒都失效，
也不会以深度放电收场。

## 配置

`data/config.json`（首次运行自动生成）：

| 键 | 默认 | 说明 |
|---|---|---|
| `thresholds` | 50/30/20/10/8 | 各层的电量触发点 |
| `dock_edge` | `"right"` | 吸附边：`left` / `right` / `null`（不吸附） |
| `pinned` | `false` | 是否固定展开（不自动收起） |
| `collapse_lock_below` | `30` | 低于此电量强制展开，不允许收起 |
| `enable_cost_layer` | `false` | L4 横幅，默认关。它有效但很烦 |
| `enable_fail_safe` | `true` | L6 自动休眠 |
| `fail_safe_countdown` | `60` | 休眠倒计时秒数 |
| `dialog_regrow_seconds` | `60` | 对话框被无视后多久再放大一次 |
| `poll_seconds` | `5` | 电量轮询间隔 |
| `capacity_wh` / `kwh_price` / `battery_price` / `battery_cycles` | 见上 | 账本参数 |

`data/stats.json` 存连续天数、累计放电量、断电事件次数。删掉它就等于重置账本。

## 测试

```bash
# 无界面自检：等级判定、速率估算、账本算法
python battery_guardian.py --self-test

# 界面冒烟测试：吸附 / 收起 / 展开 / 固定 / 拖离，会真的开窗口，跑完自动关
python selftest_ui.py
```

`selftest_ui.py` 会把配置写到临时目录，不会碰你真实的 `data/`。

调试用的参数：

| 命令 | 作用 |
|---|---|
| `--demo 15` | 用假电量预览界面，不动真实电源，也不会真休眠 |
| `--panel ledger` | 直接打开电费账本 |
| `--panel failsafe` | 直接打开休眠倒计时 |
| `--once` | 打印一次电池状态就退出 |
| `--where` | 打印配置与资源路径（排查 exe 用） |
